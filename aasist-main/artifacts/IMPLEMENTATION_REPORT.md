# AASIST AI 语音检测：实现与验证结果

本次保留原模型及权重，新增音频预处理、长录音覆盖、独立推理、验证集阈值校准、独立测试报表和数据重叠检查。仅检测 AI 合成/声音转换/克隆迹象，不覆盖真实人声剪辑取证。

## 实现

- audio_io.py：WAV/FLAC/MP3 等解码、单声道、16kHz 重采样、质量/长度/资源限制；可选 FFmpeg 回退。
- segmenter.py：64600 点窗口，32300 点步长，尾部覆盖，默认文件级均值汇总。
- app_runtime.py：冻结权重，GPU/CPU 推理；阈值绑定权重、源代码、预处理和分段规则。
- inference.py：单文件和目录检测，输出 JSON、CSV、片段分数，失败不当作真实。
- calibrate.py：在验证集上选择固定阈值，不更新模型参数。
- benchmark.py：准确率、检出率、误报率、F1、混淆矩阵、失败清单；检查校准/测试数据内容与分组重叠。
- prepare_manifests.py：生成可复现的 ASVspoof 数据清单。
- config/inference.json、artifacts/threshold.json：推理配置与校准档案。

## 实测

验证集：ASVspoof 2019 LA dev，真实/伪造各 500 条，seed=2026。
独立测试：ASVspoof 2019 LA eval，真实/伪造各 500 条，seed=2026。
文件内容哈希和说话人分组均无交叉。
阈值选择：只使用验证集，最大化平衡准确率；没有根据测试结果调整阈值。

| 指标 | 独立测试结果 |
|---|---:|
| 整体准确率（全部输入） | 93.00% |
| 伪造检出率（全部伪造输入） | 86.20% |
| 真实语音误报率 | 0.20% |
| 伪造精确率 | 99.77% |
| F1 | 92.49% |
| 文件处理成功率 | 100.00% |

混淆矩阵：431 条伪造检出，69 条伪造漏检，499 条真实正确，1 条真实误报；无处理失败。
验证集自身准确率为 99.20%，该数值用于选阈值，不是独立验收结果。

当前整体准确率超过 90%，但伪造检出率未达到 90%。这些是公开数据平衡抽样结果，不能宣称实际业务已通过验收。后续应在代表实际业务来源、语言、格式、合成器的独立数据上测试，必要时使用新的代表性验证集重新校准，并保留未用于调整的新测试集。

此前原项目 EER 0.8295% 与本次固定阈值准确率采用不同工作点和音频窗口流程，不能用 1-EER 代替本次准确率。

## 功能验证

12 项自动测试通过：包括原预处理分数回归、窗口全覆盖、立体声重采样、异常音频、阈值方向和失败计分。另通过中文路径、混合目录、WAV/FLAC/MP3、CPU 实际推理及校准/测试重叠拒绝测试。M4A/AAC 尚未在本机实际验证，需配置 FFmpeg；解码失败会明确记录。

详细命令见 README_AI_DETECTION.md。测试不修改原预训练权重。
